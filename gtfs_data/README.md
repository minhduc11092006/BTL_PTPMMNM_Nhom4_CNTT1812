# GTFS Data Directory

Thư mục này chứa các bộ dữ liệu GTFS tĩnh (dưới dạng thư mục đã giải nén hoặc tệp .zip).
Quản trị viên có thể:
1. Đặt các thư mục GTFS tải về (ví dụ các bộ Open Data Nhật Bản `odpt-...`) vào thư mục này để chọn nạp nhanh từ giao diện Quản Trị GTFS (`admin/gtfs.php`).
2. Tải trực tiếp tệp nén `.zip` thông qua form tải lên trên web.
